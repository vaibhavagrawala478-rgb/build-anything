# Contributing to BuildAnything

Forks and pull requests are very welcome.

1. **Fork** the repo (button at the top right of the GitHub page) and clone your fork.
2. `npm install` then `npm run dev`.
3. Create a branch, make your change, and run `npm run build` to make sure it compiles.
4. Open a pull request describing what you changed and why.

Good first contributions: new components in `src/engine/prefabs/`, new templates in `src/engine/templates.js`, new AI generator keywords, and UI polish.
